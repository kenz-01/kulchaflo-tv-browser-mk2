## Authority and method

Live accepted code/exact GitHub state is current implementation truth. User-tested Bravia reality is the channel acceptance truth. This dated pack records history and reasoning. Archive **what was observed at the time**; canonical files retain **what the project currently understands**. When later proof supersedes an earlier observation, preserve both with chronology.

**Standing dual-output handover protocol adapted from Events:** when requested to change TV chats, create (1) exact operational continuation, and (2) Brainstorm only when materially new product, architecture, strategy, source-learning or workflow understanding exists. Update archive manifest, chat cross-reference, Brainstorm index; create a new dated state rather than endlessly editing historical snapshots. Update decision ledger only for actual durable changes, not transient SHA noise. Git commits and PRs retain runnable status. Raw Android log files, broadcaster tokens and personal browsing data remain private/outside Git.

No raw transcript or uploaded logs are claimed to be physically archived. The current handover is a reviewed `CHAT_TEXT_CAPTURE` with direct GitHub reconciliation.
